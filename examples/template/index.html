🚀 WebMCP Template Example

A complete example showing how to integrate WebMCP with vendor-agnostic adapters

📋 Quick Start

  1. Start the WebMCP server: npx @jason.today/webmcp --mcp
  2. Get a connection token in Claude Desktop
  3. Paste the token in the WebMCP widget (bottom-right corner)
  4. Try the example tools below!

🎯 Example Tools

Once connected, you can ask Claude to:

  • "Search for items matching 'example'"
  • "Get the current status"
  • "Show me example data"
